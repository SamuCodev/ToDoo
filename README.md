# To-Doo App

Aplicación web para la gestión de tareas desarrollada con HTML, CSS y JavaScript.

## Descripción

To-Doo App permite organizar tareas de manera sencilla e interactiva, ofreciendo funcionalidades para agregar, completar y eliminar tareas en tiempo real.

Este proyecto fue desarrollado con el objetivo de fortalecer habilidades en manipulación del DOM, lógica de programación y almacenamiento local utilizando JavaScript.

---

## Características

- Agregar nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas
- Actualización dinámica de la interfaz
- Persistencia de datos usando LocalStorage
- Filtrado de tareas según su estado

---

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub

---

## Conceptos Aplicados

- Manipulación del DOM
- Eventos en JavaScript
- Arreglos y objetos
- Persistencia de datos en navegador
- Organización de interfaz de usuario
- Filtrado dinámico de datos

## Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/SamuCodev/To-Doo-App.git
```
2. Abrir la carpeta del proyecto
3. Ejecutar index.html

## Objetivo del proyecto

Desarrollar una aplicación interactiva que permita practicar lógica de programación, manipulación dinámica de elementos HTML y almacenamiento local de información
